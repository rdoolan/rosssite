About me

I've been working as a front-end web developer for the past seven years, primarily focusing on the look and feel of client websites. Before that, I worked as a graphic designer, creating HTML emails that rendered consistently across multiple email platforms.

More recently, I've developed a strong interest in web accessibility. After attending several conferences on the subject, I was inspired to help make the web more inclusive. I believe that if a web application is built correctly from the start, it can work for everyone.

I've always had a passion for creating simple, user-friendly experiences. I was recently given the opportunity to take on a UX role for a project, which I thoroughly enjoyed. The accessibility improvements I implemented have since become standard practice for new developments.

Skill set

My background in graphic design, combined with my knowledge of HTML and CSS, allows me to create UI designs and transform them into fully functional websites. As my passion for accessibility has grown, my design approach has become more refined. The small details that make a website more user-friendly are now the foundation of my work.
